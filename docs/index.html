Volna

A simple music player for Linux that shows every track as a waveform.

Get it on Flathub Source code

Features

Waveform seeking

See the shape of the track and click anywhere on it to jump there.

Playlists

Open several files or whole folders, save and load M3U playlists.

Playback speed

From 0.5× to 2× without changing the pitch — handy for podcasts and lectures.

Picks up where you left off

Your queue and current track are restored on the next launch.

Media keys

Pause and switch tracks from the keyboard, the taskbar or desktop widgets.

Install

Volna is distributed through Flathub and works on any Linux distribution with Flatpak:

flatpak install flathub io.github.jic8.Volna
